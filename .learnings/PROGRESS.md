## 📝 开发规范

### 代码风格
- 使用 TypeScript 严格模式
- 遵循 ESLint 规则
- 组件使用函数式 + Hooks

### Git 提交
- 使用语义化提交信息
- 每个功能一个分支
- 提交前运行 lint 和 build

### 测试策略
- 单元测试：核心算法、工具函数
- 集成测试：IPC 通信、API 调用
- E2E 测试：关键用户流程
