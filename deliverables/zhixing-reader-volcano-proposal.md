## 摘要

知行读书是一款基于微信读书生态的 AI 驱动阅读成长智能体桌面应用，专为 18-35 岁自我成长型阅读者设计。作品以"同步—理解—复习—应用"完整闭环为核心，通过方法论自动注入智能体、5 维上下文构建器、FSRS v5 间隔重复、本地优先混合架构与 ECDICT 离线词典等创新点，解决"读了就忘、笔记散乱、想问无门、知道做不到"四大阅读痛点。项目已发布 v1.0.0 NSIS 安装包，包含 15 大功能模块与 4 Tab 智能体管理后台，所有数据本地 SQLite 存储，AI 调用可热切换多服务商，兼顾隐私安全与智能化体验。

**关键词**：AI 阅读智能体；间隔重复；本地优先；ContextBuilder；方法论自动注入；Electron

## 三、核心创新点

### 创新点 1：方法论自动注入智能体（行业首创）

传统 AI 阅读工具只能基于用户输入的上下文生成回答，无法主动调用书中的结构化方法论。知行读书在 AI 对话中引入**方法论上下文构建器（MethodologyContextBuilder）**，实现：

1. 从书籍对应的 methodology 表检索相关方法论；
2. 按意图强度排序后注入 system prompt；
3. AI 回答时自动引用具体章节与方法论名称；
4. 对话结束后回调更新掌握度（mastery level），实现"用一次、深一层"。

效果：回答不再泛泛而谈，而是基于书籍知识框架给出可操作建议，并持续追踪用户对方法论的掌握度。

### 创新点 2：5 维上下文构建器（按需懒加载）

为降低大模型 Token 消耗并提升回答相关性，作品构建 5 个上下文维度：

1. **书籍上下文**：当前书籍的元数据、章节结构、核心观点；
2. **方法论上下文**：书中提炼的方法论与掌握度；
3. **知识卡片上下文**：用户已生成的概念/方法论/金句卡；
4. **历史记忆上下文**：该书下的历史问答与复习记录；
5. **用户画像上下文**：阅读偏好、学习目标、难度倾向。

系统按用户意图动态决定加载哪些维度。对比传统"4 段全量加载"方案，50 次中等复杂度对话平均节省 Token **33%-55%，中位数 38%**。

### 创新点 3：FSRS v5 间隔重复 + Anki 学习阶段

复习模块采用 Anki 23.10+ 同源的 **ts-fsrs 5.4.1** 引擎，基于 DSR（Difficulty-Stability-Retrievability）模型，相比传统 SM-2 算法准确度提升 20%-30%，并有效避免 "ease hell"。

- 卡片状态机：New / Learning / Review / Relearning；
- 主动回忆两段法：正面只给线索，背面揭示原文+应用场景；
- 4 种评分（Again / Hard / Good / Easy）一次性返回下次复习时间；
- 卡片可导出到 Anki，实现跨平台复习。

### 创新点 4：本地优先 + AI 云端混合架构

作品采用 Electron 三进程隔离架构：

- **主进程**：持有 sql.js（SQLite WASM）、AI SDK、微信读书 API 客户端、ECDICT 词典；
- **渲染进程**：React 19 + TypeScript strict，通过 `window.electronAPI` 与主进程通信；
- **本地服务层**：safeStorage 加密 API Key，可选 Qdrant 向量库用于语义检索。

所有笔记、划线、卡片、复习记录均保存在本地 SQLite，AI 仅按需调用，可热切换火山引擎 / DeepSeek / OpenAI / 通义等服务商，兼顾隐私与智能化。

### 创新点 5：ECDICT 13.6 MB 离线词典

每日学习模块内置从开源 ECDICT 提取的 13.6 MB JSON 词典，包含 5.9 万词条，支持：

- 悬停查词 O(1) Map 缓存；
- 动词时态、名词单复数、形容词比较级等 6 类词形变化查询；
- 词干还原与词性标注；
- 右键一键加入生词本，FSRS 自动安排复习。

### 创新点 6：智能体管理后台（4 Tab 可视化）

设置模块包含 4 Tab 智能体管理后台：

1. **数据仪表盘**：Token 用量、复习统计、功能使用分布；
2. **提示词中心（Prompt Registry）**：系统提示词、角色提示词、场景提示词分类管理；
3. **数据库浏览器**：本地 SQLite 表结构可视化；
4. **知识库**：方法论、知识卡片、用户画像统一管理。

### 创新点 7：Skill 一键生成

用户可将任意方法论一键导出为 Claude Code Skill 文件，把个人知识体系转化为可安装、可复用的 AI 技能，实现"方法论 → Skill → 实践"的二次流通。

### 4.2 技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| 桌面框架 | Electron 35 + electron-vite 2 | 跨平台桌面应用，三进程隔离 |
| 前端框架 | React 19 + TypeScript 5.6 strict | 类型安全，组件化 |
| 状态管理 | Zustand 5 | 轻量级 |
| 数据库 | sql.js (SQLite WASM) | 7+ 张表，本地优先 |
| AI 集成 | OpenAI SDK 兼容 | 火山引擎/DeepSeek/OpenAI/通义 任意切换 |
| 间隔重复 | ts-fsrs 5.4.1 | 科学算法，Anki 同源 |
| 本地词典 | ECDICT 提取版 13.6 MB | 5.9 万词条 + 词形变化 |
| RSS 抓取 | 10 个心理学/认知科学源 | CET-4/6/考研 三级难度 |
| 向量检索 | Qdrant（可选） | RAG 增强 |
| 打包 | electron-builder 25 + NSIS | 已发布 v1.0.0 安装包 |
| UI 组件 | Tailwind CSS 4 | 淡雅绿色系设计 |

### 4.3 关键技术决策

1. **三进程隔离**：主进程持有 sql.js/AI/微信读书 API，渲染进程通过 `window.electronAPI` 调用，保障安全与性能。
2. **懒加载上下文**：5 个 ContextBuilder 按意图按需加载，避免 Token 浪费。
3. **safeStorage 加密**：API Key 使用 Electron safeStorage 加密到 `%APPDATA%/zhixing-reader/secure/`。
4. **流式 Token 估算**：调用前预估，每次响应记录 provider+model+真实用量。
5. **sql.js 强制持久化**：`forceSaveDatabase` 防退出丢数据。
6. **ECDICT 纯 JSON 方案**：避免 native module 在 Electron 中的编译问题。
7. **路由懒加载**：`React.lazy + Suspense`，启动时间小于 1 秒。
