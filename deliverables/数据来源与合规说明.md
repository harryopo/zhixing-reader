# 知行读书 — 数据来源与合规说明

> **说明**：本文档说明知行读书的所有数据来源、处理方式及合规措施。
> **版本**：v1.0.0 | **最后更新**：2026-07-25

---

## 一、数据来源总览

知行读书的所有数据分为四类来源：

| 来源类型 | 具体来源 | 数据内容 | 是否离开本地 |
|---------|---------|---------|-------------|
| **外部 API** | 微信读书 Skill API | 书架、划线、笔记、书评、章节 | ✅ 仅在同步时传输 |
| **用户输入** | 设置页面手动输入 | API Key、AI 服务配置、同步策略 | ❌ 本地加密存储 |
| **AI 服务商** | 用户配置的 LLM 服务商 | AI 对话请求与响应 | ⚠️ 按服务商隐私政策处理 |
| **本地生成** | 应用内部算法 | 知识卡片、记忆条目、复习记录、统计图表 | ❌ 完全本地 |

---

## 二、外部数据来源：微信读书 Skill API

### 2.1 API 基本信息

- **网关地址**：`https://i.weread.qq.com/api/agent/gateway`
- **鉴权方式**：`Authorization: Bearer {apiKey}`，API Key 以 `wrk-` 开头
- **协议**：HTTPS
- **SDK 版本**：`skill_version: "1.0.5"`

### 2.2 调用的接口

| 接口 | 用途 | 触发时机 |
|------|------|---------|
| `/shelf/sync` | 拉取书架列表 | 测试连接、手动同步、自动同步 |
| `/book/bookmarklist` | 拉取某本书的划线 | 同步书籍内容、知识卡片蒸馏 |
| `/review/list/mine` | 拉取某本书的笔记/书评 | 同步书籍内容、AI 对话上下文 |
| `/book/chapterinfo` | 拉取某本书的章节信息 | 同步书籍内容、展示章节结构 |

### 2.3 数据流向

```
用户点击「同步」
    │
    ▼
本地构建 HTTPS 请求（含 API Key）
    │
    ▼
微信读书开放网关（i.weread.qq.com）
    │
    ▼
返回 JSON 数据（书架/划线/笔记/章节）
    │
    ▼
本地解析 → 写入 SQLite 数据库
```

**关键点**：
- 数据直接从微信读书 API 传输到本地，不经过任何中间服务器
- 同步完成后，原始 API 响应不会被保留，仅保留结构化后的本地数据
- 用户可随时删除本地数据，无残留

### 2.4 数据最小化

知行读书仅调用上述 4 个接口，且每个接口仅请求必要字段：
- 不请求用户个人信息（昵称、头像、手机号等）
- 不请求阅读时长、阅读速度等行为数据
- 不请求好友关系、社交数据

## 三、用户输入数据

### 3.1 API Key 与配置

- **微信读书 API Key**：通过 Electron `safeStorage.encryptString()` 加密存储
- **AI 服务商 API Key**：同样通过 `safeStorage` 加密存储
- **其他配置**：同步频率、主题偏好、语言设置等，存储在本地 JSON 配置文件中

### 3.2 敏感信息处理

| 信息类型 | 存储方式 | 加密方式 |
|---------|---------|---------|
| 微信读书 API Key | 独立 `.enc` 文件 | Electron safeStorage（系统级加密） |
| AI 服务商 API Key | 独立 `.enc` 文件 | Electron safeStorage（系统级加密） |
| 其他设置 | `settings.json` | 明文（不含敏感信息） |

**safeStorage 说明**：
- Windows：使用 DPAPI（Data Protection API）
- macOS：使用 Keychain
- Linux：使用 libsecret / GNOME Keyring

即使应用配置文件被泄露，加密后的 API Key 也无法被解密（除非拿到用户系统凭证）。

## 四、AI 服务商数据

### 4.1 数据发送内容

当用户与 AI 对话时，以下数据会发送到用户配置的 AI 服务商：

- **用户消息**：用户输入的原始文本
- **上下文数据**：5 维上下文（书籍摘要、知识卡片、记忆条目、方法论、用户画像）
- **系统提示**：根据用户意图动态组装的教学策略提示词

### 4.2 数据发送方式

```
本地构建请求
    │
    ▼
HTTPS 直连 AI 服务商（如 OpenAI、DeepSeek、Anthropic）
    │
    ▼
AI 服务商返回响应
    │
    ▼
本地保存对话历史到 SQLite
```

**关键点**：
- AI 请求直接从用户电脑发送到服务商，不经过任何代理
- 不记录、不上传用户的 API Key 到第三方（除服务商本身外）
- 对话历史仅存储在本地 SQLite 中

### 4.3 服务商隐私政策

不同 AI 服务商对数据的处理政策不同，用户应自行阅读并同意相应隐私政策：

- OpenAI：<https://openai.com/privacy>
- DeepSeek：<https://www.deepseek.com/privacy>
- Anthropic：<https://www.anthropic.com/privacy>
- Moonshot：<https://www.moonshot.cn/privacy>

**知行读书开发者不对 AI 服务商的数据处理行为负责。**

## 五、本地生成数据

### 5.1 数据类型

以下数据完全在本地生成和存储，永不离开用户电脑：

| 数据类型 | 生成方式 | 存储位置 |
|---------|---------|---------|
| 知识卡片 | AI 蒸馏（concept / methodology / quote） | SQLite `flashcards` 表 |
| 记忆条目 | AI 生成（偏好 / 事实 / 反馈） | SQLite `memories` 表 |
| 复习记录 | FSRS v5 算法计算 | SQLite `reviews` 表 |
| 生词本 | 用户添加或 AI 提取 | SQLite `vocabulary` 表 |
| 对话历史 | 用户与 AI 交互 | SQLite `chat_sessions` / `chat_messages` 表 |
| 统计图表 | ECharts 本地渲染 | 内存中渲染，不持久化 |

### 5.2 数据导出

用户可在「设置 → 数据管理」中导出全部数据为 JSON 文件。导出操作完全在本地完成，不涉及网络传输。

## 六、合规措施

### 6.1 本地优先架构

- 所有核心数据存储在本地 SQLite（sql.js WASM）
- 除微信读书同步和 AI 对话外，应用可完全离线运行
- 用户拥有数据的完全控制权

### 6.2 加密存储

- API Key 通过系统级加密存储（Electron safeStorage）
- 即使应用配置文件被泄露，敏感信息也无法被解密

### 6.3 无追踪 SDK

应用**不包含**以下类型的 SDK：
- ❌ 用户行为分析（如 Google Analytics、Mixpanel）
- ❌ 崩溃上报（如 Sentry、Bugsnap）
- ❌ 广告 SDK
- ❌ 第三方推送

### 6.4 网络请求最小化

应用仅会在以下情况发起网络请求：

| 服务 | 触发条件 | 用户可控性 |
|------|---------|-----------|
| 微信读书 API | 用户主动点击同步 | 可关闭自动同步 |
| AI 服务商 API | 用户主动发起 AI 对话 | 不配置 API Key 即关闭 |
| GitHub Releases API | 应用启动时检查更新 | 可关闭自动检查更新 |

### 6.5 开源可审计

- 源代码完全开源，托管于 GitHub：<https://github.com/harryopo/zhixing-reader>
- 任何人都可以审查代码，验证本说明中的承诺
- 欢迎提交 Issue 指出任何隐私或合规问题

### 6.6 日志管理

- 日志仅存储在本地，不会自动上传
- 日志不包含敏感数据（API Key、Cookie、对话内容等）
- 如需反馈 Bug，用户需手动复制日志并自行删除敏感信息

## 七、用户权利

### 7.1 数据访问权

用户可随时查看本地数据库中的所有数据。

### 7.2 数据修改权

用户可直接编辑本地数据，或通过应用界面修改配置、删除记录。

### 7.3 数据删除权

用户可：
- 删除单条记录（如删除某张卡片、某条记忆）
- 批量删除（如清空某本书的所有数据）
- 完全卸载（删除应用数据文件夹，所有数据将被清除）

### 7.4 数据导出权

用户可随时导出全部数据为 JSON 格式，用于备份或迁移。

### 7.5 数据可携权

由于数据存储在标准 SQLite 格式中，用户可使用任意 SQLite 工具读取和导出数据。

## 九、合规声明

### 9.1 适用法律

本应用努力符合以下法规的要求：
- 《中华人民共和国个人信息保护法》
- 《中华人民共和国网络安全法》
- 《中华人民共和国数据安全法》
- GDPR（欧盟通用数据保护条例，如适用）

### 9.2 数据出境

- 本地生成的数据**不会出境**，完全存储在用户设备上
- 微信读书 API 数据来源于中国境内服务器（`weread.qq.com`）
- AI 服务商数据出境取决于用户配置的服务商所在地

### 9.3 儿童隐私

本应用不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。如发现误收集，请联系我们删除。

### 9.4 数据泄露应对

由于采用本地优先架构，不存在 centralized database 泄露风险。即使设备丢失，只要系统加密 intact，数据仍安全。

## 十、用户指南

### 10.1 如何完全离线使用

1. 不配置微信读书 API Key（或配置后不点击同步）
2. 不配置 AI 服务商 API Key（或关闭 AI 功能）
3. 关闭自动检查更新

满足以上条件后，应用可完全离线运行。

### 10.2 如何安全地分享 Bug

如需在 GitHub Issues 中反馈 Bug：
1. 导出相关日志文件
2. **手动删除**日志中的敏感信息（API Key、Cookie、对话内容等）
3. 上传脱敏后的日志

### 10.3 如何彻底卸载

1. 卸载应用
2. 删除应用数据文件夹（见第一节存储位置）
3. 所有数据将被完全清除
