## 一、安装

### 1.1 下载安装包

1. 打开 Releases 页面：https://github.com/harryopo/zhixing-reader/releases/tag/v1.0.0
2. 下载 `ZhixingReader-Setup-1.0.0.exe`
3. 双击运行安装程序，按提示完成安装
4. 桌面会出现 **知行读书** 快捷方式

### 1.2 启动应用

双击桌面快捷方式即可启动。首次启动会自动创建本地数据文件夹。

---

## 二、首次配置

### 2.1 配置 AI 服务

1. 打开应用，进入左侧菜单的 **设置**
2. 选择 **AI 配置**
3. 填写以下信息：
   - **AI 提供商**：选择你使用的服务商，如 OpenAI、DeepSeek、通义、自定义
   - **API 地址**：对应服务商的接口地址
   - **API Key**：你的密钥，应用会加密保存在本地
   - **模型**：填写模型名称，如 `gpt-4o`、`deepseek-chat`、`qwen-turbo`
4. 点击 **保存**

### 2.2 配置微信读书同步（可选）

1. 在 **设置** 中选择 **微信读书**
2. 在 **API Key** 中粘贴微信读书 Cookie
3. 开启 **自动同步**

**Cookie 获取方法**：
1. 浏览器打开 https://weread.qq.com/ 并登录
2. 按 F12 打开开发者工具
3. 进入 Application / Cookies
4. 复制 `wr_skey` 或完整 Cookie
5. 粘贴到知行读书设置页

## 三、书架与同步

### 3.1 同步微信读书

1. 进入左侧菜单的 **书架**
2. 点击右上角 **同步微信读书**
3. 在弹出窗口中确认 Cookie，点击 **开始同步**
4. 顶部进度条走到 100% 后，书架会显示你的书籍

**同步内容**：
- 书架上的书名、作者、封面、阅读进度
- 划线高亮和章节位置
- 个人笔记
- 公开书评

### 3.2 浏览书籍

- 书架以卡片形式展示你的书
- 悬停可查看每本书的划线数、笔记数、知识卡片数
- 点击书籍进入详情页

### 3.3 书籍详情

进入书籍详情后，默认展示 **笔记** 页签，也可切换查看：
- 划线高亮
- 知识卡片
- 方法论
- 相关讨论

## 四、AI 对话

### 4.1 开始对话

1. 进入左侧菜单的 **AI 对话**
2. 左侧是会话列表，可新建或切换会话
3. 中间是对话区域，输入问题后按回车发送
4. 右侧会显示当前对话加载了哪些上下文

### 4.2 对话特点

- **基于你的笔记回答**：AI 会结合你当前书籍的划线、笔记、知识卡片来回答
- **自动引用方法论**：如果书中提取了方法论，AI 会自动引用
- **流式输出**：回答逐字显示，可随时停止生成

### 4.3 常见提问方式

| 你说 | AI 会 |
|------|-------|
| 什么是 X / 解释一下 X | 直接给出概念解释 |
| 为什么 / 你怎么看 / 对比 A 和 B | 深入分析、追问引导 |
| 教我 / 考考我 / 帮我复述 | 用费曼学习法引导你输出 |
| 你好 / 谢谢 | 简洁回应 |

## 五、复习

### 5.1 开始复习

1. 进入左侧菜单的 **复习**
2. 顶部会显示今日待复习数量和预计用时
3. 点击 **开始复习**

### 5.2 复习流程

1. 先看卡片正面，尝试回忆答案
2. 点击 **显示答案** 查看背面
3. 根据记忆程度选择评分：
   - **Again**：不记得，尽快重学
   - **Hard**：记得但吃力
   - **Good**：正常记住
   - **Easy**：非常轻松
4. 系统会自动安排下次复习时间

### 5.3 调整复习节奏

如果你觉得复习太频繁或太稀疏，可以在 **设置 → 数据与存储 → FSRS 参数** 中调整：
- **请求级别**：数值越高，复习越频繁
- **难度衰减**：数值越低，记忆间隔越长
- **最大间隔**：单张卡片最长复习间隔天数

## 六、知识卡片

### 6.1 查看知识卡片

1. 进入左侧菜单的 **知识卡片**
2. 顶部可按类型筛选：全部、概念、方法论、金句
3. 点击卡片可翻转查看背面

### 6.2 卡片内容

- **正面**：标题、内容、类型标签、所属书籍
- **背面**：原文解读、应用场景、掌握度进度条

### 6.3 生成知识卡片

知识卡片主要来自两种方式：
- 阅读时自动或手动从划线蒸馏生成
- AI 根据你的笔记自动提炼

## 七、每日学习与生词本

### 7.1 每日学习

1. 进入左侧菜单的 **每日学习**
2. 阅读当日推送的英文文章
3. 鼠标悬停在单词上，会弹出音标、词性、释义
4. 右键单词可 **加入生词本**
5. 点击段落旁的 **翻译** 可查看该段中文翻译

### 7.2 生词本

1. 进入左侧菜单的 **生词本**
2. 查看已收藏的单词
3. 点击单词可查看音标、词性、释义、例句
4. 已收藏的单词会进入复习计划

## 八、统计与 Token 监控

### 8.1 统计

进入左侧菜单的 **统计**，可查看：
- 累计阅读书籍、笔记数量
- 复习趋势图
- FSRS 各阶段卡片分布
- Token 用量与服务商分布

### 8.2 Token 监控

进入左侧菜单的 **Token 监控**，可查看：
- 今日 AI 调用消耗的 Token 数
- 各服务商 Token 占比
- 近 7 天或 30 天用量趋势
- 每次 AI 调用的详细记录
- 支持导出 CSV

## 九、设置中心

左侧菜单进入 **设置** 后，可看到以下分类：

### 9.1 账户

用于账号信息展示。当前版本可先使用本地信息，后续会支持继承微信读书个人信息。

### 9.2 AI 配置

- 配置 AI 提供商、API 地址、API Key、模型
- 管理提示词模板：可编辑内置模板，也可新建自定义模板

### 9.3 智能体编排

调整 AI 对话时的行为偏好，包括意图识别、教学策略、上下文预算等。

### 9.4 微信读书

管理微信读书 Cookie 和自动同步开关。

### 9.5 外观

切换深色主题或浅色主题。

### 9.6 数据与存储

- **存储用量**：查看本地数据库、缓存、向量库占用
- **缓存管理**：清理 API 缓存、对话历史、向量索引
- **数据导入导出**：
  - 导出全部数据（JSON）
  - 导出笔记（Markdown）
  - 导出复习数据（CSV）
  - 导入数据（JSON）
- **FSRS 参数**：调整复习算法参数
- **重置数据库**：清空全部本地数据并重启应用，操作前建议先导出备份

### 9.7 关于

查看应用信息、检查更新、反馈与帮助、开源许可。

## 十一、常见问题

### 11.1 安装与启动

**Q：安装包被安全软件拦截？**

A：这是 Electron 应用的常见现象。项目已开源，可自行从源码编译验证。

**Q：启动失败或白屏？**

A：
1. 确认系统为 Windows 10/11 64 位
2. 检查是否有安全软件拦截
3. 尝试右键 **以管理员身份运行**

### 11.2 微信读书同步

**Q：同步失败，提示 Cookie 无效？**

A：
1. Cookie 有效期约 30 天，过期后需要重新获取
2. 重新登录微信读书网页版获取新 Cookie
3. 检查网络连接是否正常

**Q：同步后书架上没有书？**

A：
1. 确认微信读书账号里有书籍
2. 重新点击同步，观察是否有报错
3. 刷新书架页面

### 11.3 AI 对话

**Q：AI 没有回复或很慢？**

A：
1. 检查 API Key 是否填写正确
2. 检查网络是否正常
3. 确认模型名称与所选服务商匹配
4. 查看 Token 监控是否还有可用额度

**Q：Token 消耗太快？**

A：
1. 系统默认按需加载上下文，不会主动浪费
2. 可适当降低上下文预算
3. 在 Token 监控中查看哪项功能消耗最多

### 11.4 复习

**Q：没有可复习的卡片？**

A：
1. 先从阅读数据中生成或导入卡片
2. 新生成的卡片需要等待到设定时间才会进入复习

**Q：复习间隔总是不合适？**

A：在 **设置 → 数据与存储 → FSRS 参数** 中调整：
- 提高请求级别：复习更频繁
- 降低难度衰减：延长间隔
- 增大最大间隔：允许更长间隔

### 11.5 数据与备份

**Q：数据存在哪里？**

A：所有数据都保存在本地 SQLite 数据库中，不会自动上传。

**Q：如何备份？**

A：在 **设置 → 数据与存储** 中使用 **导出全部数据（JSON）**。

**Q：重置数据库后能恢复吗？**

A：不能直接恢复，所以重置前请先导出备份；重置后可以通过 **导入数据** 恢复。
