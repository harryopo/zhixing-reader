## 一、项目背景与痛点分析

### 1.1 行业背景

在知识付费与自我提升浪潮下，阅读仍是最高密度的学习方式之一。微信读书作为国内主流阅读平台，月活用户过亿，但用户在平台上产生的划线、笔记、书评等数据长期处于"散落"状态——无法导出、难以复习、无法与 AI 结合进行深度理解。

### 1.2 核心痛点

| 痛点 | 现状描述 | 影响 |
|------|---------|------|
| **笔记散落** | 微信读书划线无法批量导出，数据被平台锁定 | 用户无法二次整理、跨设备使用 |
| **读了就忘** | 缺乏科学复习机制，阅读效果随时间衰减 | 知识留存率低，阅读投入产出比差 |
| **想问无门** | 遇到不懂的段落无法即时获得深度解析 | 阅读体验中断，理解深度受限 |
| **知道做不到** | 学到的概念缺乏应用场景与掌握度追踪 | 知识无法转化为能力 |
| **英语学习脱节** | 背单词与阅读场景割裂，效率低下 | 词汇记忆缺乏语境支撑 |
| **隐私担忧** | 云端 AI 需要上传个人笔记数据 | 敏感阅读数据存在泄露风险 |

### 1.3 目标用户

- **核心用户**：18-35 岁自我成长型阅读者，微信读书重度用户
- **使用场景**：睡前通勤、周末集中阅读、复习备考、英语学习
- **真实场景**：开发者本人即核心用户（年阅读量 50+ 本书）

## 二、解决方案与创新点

### 2.1 一句话定位

**知行读书是基于微信读书生态的 AI 驱动阅读成长智能体，解决"读了就忘、笔记散乱、想问无门、知道做不到"四大阅读痛点。**

### 2.2 核心创新点

#### 创新点 1：Agent 编排引擎 — 从「问答机器」到「学习教练」

**为什么是这个智能体？**
- **场景切入新颖**：市面上没有专门为「阅读后理解与复习」设计的 AI 智能体。通用 AI 工具（ChatGPT/Claude）需要用户手动提供上下文，无法自动理解「用户正在读什么书、学到了什么、哪里没懂」。
- **真实痛点驱动**：开发者本人作为年阅读 50+ 本书的微信读书重度用户，亲身经历「划线散落、读了就忘、想问无门」的痛点，产品从第一天就是真实需求驱动，不是为比赛而做。
- **交互逻辑创新**：不是简单的「用户问 → LLM 答」，而是经过六步编排，让 AI 成为懂你读什么、懂你学到哪、懂怎么教你的苏格拉底式阅读伙伴。

**六步编排流水线**：
```
用户提问
   │
   ▼
① 意图分类  ──→  ② 策略选择  ──→  ③ 难度调整  ──→  ④ 上下文构建  ──→  ⑤ 系统提示  ──→  ⑥ 流式响应
```

| 步骤 | 技术实现 | 延迟 | 说明 |
|------|---------|------|------|
| ① 意图分类 | 关键词匹配 + 对话上下文分析 | 0ms | 识别知识查询 / 深度讨论 / 教学练习 / 闲聊问候四类意图，不依赖 LLM |
| ② 策略选择 | 意图 × Bloom 等级映射表 | 0ms | 苏格拉底式提问 / 费曼学习法 / 直接回答 / 评测 |
| ③ 难度调整 | 连续答对/答错率追踪 + 30 分钟冷却 | 0ms | 答对率 ≥ 85% 升级，答错率 ≥ 60% 降级，避免难度抖动 |
| ④ 上下文构建 | 5 维 ContextBuilder 懒加载 | 50-200ms | 书籍 / 方法论 / 知识卡片 / 记忆 / 用户画像，总预算 4000 tokens |
| ⑤ 系统提示 | 模板引擎 `renderTemplate` 实时填充 | 10ms | 人设 + 策略 + 难度 + 掌握概念拼成系统提示 |
| ⑥ 流式响应 | Vercel AI SDK `streamText()` | 网络延迟 | 逐 token 推送，支持随时取消，响应后更新掌握度和长期记忆 |

**核心设计理念**：
- **教学策略驱动**：不是所有问题都直接回答。深度讨论用苏格拉底追问，练习用费曼复述
- **难度自适应**：Bloom 六级认知层次 + 答题反馈自动升降，避免「太难放弃 / 太简单无聊」
- **RAG 上下文**：回答基于用户自己的读书笔记 + 知识卡片，而非模型通用知识
- **记忆持久化**：对话中抽取偏好 / 事实 / 反馈三类记忆，跨会话记住用户

**技术栈**：自研 `orchestrator.ts`（277 行）串联六步，Vercel AI SDK 7.x 流式输出，`@ai-sdk/openai-compatible` 一套代码兼容多服务商。

#### 创新点 2：知识卡片 + 方法论蒸馏 — 从「划线」到「知识资产」

**为什么是这个创新？**
- **场景切入新颖**：现有工具要么只能手动制卡（Anki），要么只能简单总结（ChatGPT），没有完整的「划线 → 蒸馏 → 复习 → 应用」闭环。我们将 AI 蒸馏与 FSRS 复习、方法论提取、Skill 生成串联，形成知识资产化流水线。
- **真实痛点解决**：微信读书用户每年产生大量划线，但 90% 以上读完就忘。AI 自动蒸馏让用户零成本获得可复习的知识卡片。

**知识卡片蒸馏流程**：
```
用户划线 → 意图识别 → AI 提炼 → 卡片生成 → FSRS 调度复习
```

**三类知识卡片**：

| 类型 | 说明 | 应用场景 |
|------|------|---------|
| concept（概念卡） | 核心概念、关键术语 | 概念辨析、定义记忆 |
| methodology（方法论卡） | 操作步骤、思维模型 | 实践指导、问题解决 |
| quote（金句卡） | 精彩原文、启发性语句 | 写作素材、灵感触发 |

**每张卡片包含**：
- **正面**：标题、内容、类型标签、反向链接到原文
- **背面**：AI 生成的「解读」和「应用场景」、掌握度进度条

**方法论提取与复用**：
- AI 从划线中自动提取结构化方法论（name / triggerScenario / description / steps / outputFormat / examples / tags）
- 方法论可被 Agent 在对话时自动检索注入
- **Skill 一键生成**：将方法论转化为可安装的 Claude Code Skill 文件（YAML 格式），实现「阅读 → 提炼 → 复用」的闭环

**技术实现**：
- 按批调用 AI（默认 20 条/批），提取结构化 JSON
- `extractAndParseJSON` 解析 + `repairJSON` 兜底修复中文引号等
- 全程通过 `onDistillProgress` 事件回传进度

#### 创新点 3：微信读书 Skill API 集成 — 开放生态接入

**为什么选择这个切入点？**
- **场景切入新颖**：知行读书不是另一个封闭的笔记应用，而是依托微信读书开放网关的 Skill API 能力，实现与微信读书生态的深度集成。用户无需离开微信读书生态，即可获得 AI 增强的阅读体验。
- **真实痛点解决**：微信读书用户数据被平台锁定，无法导出。通过 Skill API，我们实现了增量同步、自动合并、防重复导入，让用户真正拥有自己的阅读数据。

**API 接入方式**：
- 通过微信读书开放网关的 **API Key** 鉴权（`wrk-` 开头）
- 调用 `/shelf/sync` 等接口拉取书架、划线、笔记
- 支持增量同步、自动合并、防重复导入

**集成功能**：
- **书架同步**：一键拉取书名、作者、封面、阅读进度
- **划线抓取**：结构化存储高亮内容 + 章节位置
- **笔记同步**：个人笔记 + 时间戳
- **书评同步**：公开书评数据

**技术特点**：
- Cookie 鉴权机制（API Key 通过 Electron safeStorage 加密存储）
- 增量同步算法（只拉取变更部分）
- 支持 1 天 / 3 天 / 7 天自动同步频率
- 数据结构化存储（books / highlights / notes / reviews 表）

#### 创新点 4：本地优先 + AI 云端的混合架构

- 笔记数据本地 SQLite（sql.js WASM），永不上传
- AI 调用可切换多服务商（OpenAI / DeepSeek / 通义 / 自定义）
- 敏感数据 Electron safeStorage 加密存储
- 离线可用（除 AI 对话需联网）

#### 创新点 5：FSRS v5 间隔重复算法

采用 Anki 同源 **ts-fsrs 5.4.1**（open-spaced-repetition 官方库）：
- DSR 模型（Difficulty / Stability / Retrievability）
- 21 参数权重，比传统 SM-2 准确度高 20-30%
- Anki 风格学习阶段（New → Learning → Review → Relearning）
- `repeat()` 预览 4 种评分结果
- 数据可与 Anki 互通

#### 创新点 6：ECDICT 离线词典 + 词形变化

- 13.6MB JSON 文件，约 8 万词条
- 悬停查词 O(1) 响应（280ms 防抖）
- 词形变化查询（6 类变形）+ 词干还原
- 右键加入生词本，自动进入复习计划

## 四、核心功能模块

### 4.1 微信读书 Skill API 同步

**功能**：依托微信读书开放网关 Skill API，一键同步阅读数据到本地。

**技术实现**：
- **Skill API 鉴权**：通过 API Key（`wrk-` 开头）调用 `/shelf/sync` 等接口
- 增量同步算法（只拉取变更部分）
- 自动合并，防重复导入
- 数据结构化存储（books / highlights / notes / reviews 表）

**同步内容**：
- 书架列表（书名、作者、封面、阅读进度）
- 划线笔记（高亮内容 + 章节位置）
- 阅读笔记（个人笔记 + 时间戳）
- 公开书评

### 4.2 Agent 编排对话

**功能**：基于六步编排的智能对话，支持多意图识别和教学策略。

**技术实现**：
- **六步流水线**：意图分类 → 策略选择 → 难度调整 → 上下文构建 → 系统提示 → 流式响应
- **意图分类**：关键词匹配 + 对话上下文分析（零延迟）
- **策略选择**：苏格拉底式提问 / 费曼学习法 / 知识查询 / 评测
- **5 维上下文懒加载**：按需加载，Token 节省 38-55%
- **流式输出**：Vercel AI SDK `streamText()` 逐 token 推送
- **方法论自动注入**：AI 回答时自动引用书中方法论

**意图分类**：

| 意图 | 识别词示例 | AI 策略 |
|------|-----------|---------|
| 知识查询 | 什么是、解释、定义 | 直接回答 |
| 深度讨论 | 为什么、对比、分析 | 苏格拉底式追问 |
| 教学练习 | 教我、考考我、复述 | 费曼学习法 |
| 闲聊问候 | 你好、谢谢 | 轻量回应 |

### 4.3 知识卡片 + 方法论蒸馏

**功能**：从划线笔记自动蒸馏三类知识卡片和结构化方法论。

**技术实现**：
- **AI 蒸馏**：按批调用 AI 提取结构化 JSON
- **三类卡片**：concept（概念）/ methodology（方法论）/ quote（金句）
- **方法论提取**：name / triggerScenario / description / steps / outputFormat / examples / tags
- **Skill 生成**：将方法论转化为 Claude Code Skill YAML 文件
- **翻转交互**：正面内容 + 背面解读 + 应用场景
- **掌握度追踪**：进度条实时更新

**蒸馏流程**：
1. 前端调用 `knowledgeCard.distill(bookId, bookTitle)` IPC
2. 后端从 DB 取该书全部划线（上限 60 条）
3. 按批（默认 20 条/批）调用 AI 蒸馏
4. AI 返回结构化 JSON（类型 / 标题 / 内容 / 解读 / 应用 / 标签）
5. 写入 `knowledge_cards` 表，关联 `book_id` 和 `source_highlight_id`

### 4.4 科学间隔复习（FSRS v5）

**功能**：基于 Anki 同源 FSRS v5 (DSR) 算法的间隔重复系统。

**技术实现**：
- **ts-fsrs 5.4.1**：Anki 同源算法，21 参数权重
- **DSR 模型**：Difficulty / Stability / Retrievability
- **学习阶段状态机**：New → Learning → Review → Relearning
- **评分体系**：Again(1) / Hard(2) / Good(3) / Easy(4)
- **遗忘曲线**：完整实现 `(1 + factor·t/9S)^decay`

**特色**：
- 比传统 SM-2 准确度高 20-30%
- 数据可与 Anki 互通
- `repeat()` 预览 4 种评分结果
- Anki 风格 learning_stage 防 "ease hell"

### 4.5 英语学习

**功能**：每日英文文章推送 + 悬停查词 + 生词本管理。

**技术实现**：
- **ECDICT 13.6MB JSON**：约 8 万词条，纯 JSON 方案
- **悬停查词**：O(1) Map 缓存，280ms 防抖
- **词形变化**：6 类变形 + 词干还原
- **RSS 抓取**：10 个心理学/认知科学源
- **难度分级**：CET-4/6/考研 三级难度
- **右键加词**：一键加入生词本，自动进入复习计划

### 4.6 数据看板

**功能**：Token 用量监控 + 复习统计 + 会话历史。

**技术实现**：
- **Apache ECharts 5.5.1**：6 个图表组件（环形图 / 柱图 / 仪表盘 / 分组堆叠）
- **Recharts 3.8.1**：Stats 页简单图表
- **Token 监控**：CCS-CSwitch 风格大数字 + 折线图趋势
- **CSV 导出**：支持导出 Token 用量为 CSV

## 五、关键技术实现

### 5.1 微信读书 Skill API 集成

**接入方式**：通过微信读书开放网关的 API Key 鉴权，调用 Skill API 拉取数据。

**核心接口**：
- `/shelf/sync` — 拉取书架列表
- `/book/get` — 获取书籍详情
- `/note/list` — 获取划线笔记
- `/review/list` — 获取书评

**技术实现**：
- API Key 通过 Electron safeStorage 加密存储
- 增量同步：基于 `readUpdateTime` / `lastReadTime` 判断变更
- 自动合并：新导入 + 更新计数，防重复
- 错误处理：401 认证失败 / 499 超时 / 500 服务器错误

### 5.2 IPC 通信架构

**设计模式**：前后端通过 IPC（Inter-Process Communication）通信，使用 `contextBridge` 安全暴露 API。

**通道分组**（100+ 通道）：

| 分组 | 前缀 | 用途 |
|------|------|------|
| 微信读书 | `WEREAD:*` | Skill API 调用、同步 |
| AI 服务 | `AI:*` | 对话、流式、Token |
| 间隔重复 | `FSRS:*` | 复习引擎 |
| 系统操作 | `SYSTEM:*` | 保存、重置 |
| 管理后台 | `ADMIN:*` | 后台管理 |
| 书籍操作 | `BOOK:*` | 书籍 CRUD |
| 笔记操作 | `NOTE:*` | 笔记 CRUD |
| 知识卡片 | `CARD:*` | 卡片操作 |
| 方法论 | `METHODOLOGY:*` | 方法论管理 |
| 词汇学习 | `VOCABULARY:*` | 词汇管理 |
| 复习 | `REVIEW:*` | 复习操作 |
| 每日学习 | `DAILY_LEARNING:*` | 文章推送 |
| 设置 | `SETTINGS:*` | 配置管理 |
| 提示词 | `PROMPT:*` | 模板管理 |

**开发规范**：
1. 在 `shared/ipc-channels.ts` 注册常量
2. 在 `electron/ipc.ts` 注册 handler
3. 在 `electron/preload.ts` 暴露 API
4. 返回 `{ success, data }` 或抛 Error

### 5.3 数据库 Schema

**技术选型**：sql.js（SQLite WASM），无原生依赖，跨平台。

**核心表结构**（16 张表）：

| `methodologies` | 方法论 | id, book_id, title, content, mastery_level |
| `knowledge_cards` | 知识卡片 | id, book_id, type, title, content, interpretation |

### 5.4 智能体编排引擎

**六步流水线**：

```
用户提问
   │
   ▼
① 意图分类  →  ② 策略选择  →  ③ 难度调整  →  ④ 上下文构建  →  ⑤ 系统提示  →  ⑥ 流式响应
```

**技术细节**：

| 步骤 | 实现 | 延迟 |
|------|------|------|
| 意图分类 | 关键词匹配 + 对话上下文分析 | 0ms（不依赖 LLM） |
| 策略选择 | 意图 × Bloom 等级映射表 | 0ms |
| 难度调整 | 连续答对/答错率追踪，30 分钟冷却 | 0ms |
| 上下文构建 | 5 维 ContextBuilder 懒加载 | 50-200ms |
| 系统提示 | 模板引擎 `renderTemplate` 填充 | 10ms |
| 流式响应 | Vercel AI SDK `streamText()` | 网络延迟 |

**状态追踪**：
- 概念掌握度（0-100%）
- 方法论练习次数和掌握度
- Bloom 等级（L1-L6）
- 长期记忆（偏好/事实/反馈三类）

### 5.5 FSRS v5 适配层

**设计目标**：内部算法替换为 `ts-fsrs`，对外 100% API 兼容，零破坏性变更。

**适配策略**：

| 项目 API | ts-fsrs 映射 | 说明 |
|---------|-------------|------|
| `CardState` | `State` | New=0, Learning=1, Review=2, Relearning=3 |
| `Rating` | `Grade` | Again=1, Hard=2, Good=3, Easy=4 |
| `step` | `learning_steps` 索引 | `step = state === Review ? 2 : max(0, ls - 1)` |
| `reviewCard()` | `scheduler.next()` | 计算下次复习 |
| `repeat()` | `scheduler.repeat()` | 预览 4 种评分结果 |

**学习步骤配置**：
```
learning_steps: ['1m', '10m', '10m']
```

| 操作序列 | 项目状态 | 项目 step | ts-fsrs ls |
|----------|---------|-----------|-----------|
| New + Good | Learning | 0 | 1 |
| Learning + Good (1st) | Learning | 1 | 2 |
| Learning + Good (2nd) | Review（毕业）| 2 | 0 |
| Learning + Again | Learning | 0 | 0 |

**测试覆盖**：38 个单元测试（vitest）
- 原有 18 个冒烟测试（100% 通过）
- 新增 20 个适配层测试

### 5.6 图表库架构

**双库选型策略**：

| 场景 | 库 | 包体积 | 渲染 | 理由 |
|------|----|--------|------|------|
| AdminDashboard | Apache ECharts 5.5.1 | ~20KB（业务 chunk） | Canvas | 6 个图表，类型多样，性能高 |
| Stats 页 | Recharts 3.8.1 | ~200KB | SVG | 简单场景够用 |

**按需引入策略**：
```typescript
import * as echarts from 'echarts/core'
import { BarChart, GaugeChart, PieChart } from 'echarts/charts'
import { DatasetComponent, GridComponent, LegendComponent } from 'echarts/components'
import { CanvasRenderer } from 'echarts/renderers'
```

**只引入 3 个图表类型 + 7 个组件**，vendor chunk 比全量小 ~40%。

**懒加载策略**：
- AdminDashboard 是 `React.lazy + Suspense` 路由
- 访问 `/admin` 前不下载 ECharts
- 主入口体积不受影响

## 七、差异化优势

### 7.1 vs 通用 AI 工具（ChatGPT/Claude）

| 维度 | 通用工具 | 知行读书 |
|------|---------|---------|
| 场景适配 | 通用对话，需自带上下文 | 专为阅读场景设计，开箱即用 |
| 数据归属 | 上传云端，隐私风险 | 本地 SQLite，永不上传 |
| 工作流 | 单点问答 | 同步→蒸馏→复习→应用 闭环 |
| 成本 | 订阅 $20/月 | 本地零成本 + AI 按需调用 |
| 个性化 | 无 | 5 维 ContextBuilder + Agent 编排 + 长期记忆 |

### 7.2 vs Anki（间隔重复）

| 维度 | Anki | 知行读书 |
|------|------|---------|
| 制卡成本 | 手动或插件 | AI 自动蒸馏三类卡片 + 方法论 |
| 上下文 | 孤立的卡片 | 关联到具体书/笔记/方法论，Agent 自动注入 |
| 算法 | SM-2 | FSRS + Anki 学习阶段 + 主动回忆 |
| 集成 | 独立 | 与微信读书 Skill API、AI 对话深度整合 |

### 7.3 vs 微信读书内置 AI

| 维度 | 微信读书 AI | 知行读书 |
|------|------------|---------|
| 数据范围 | 仅当前章节 | 全书笔记 + 方法论 + 历史记忆 + Agent 编排 |
| 复习 | 无 | FSRS 科学复习 |
| 导出 | 微信生态封闭 | 笔记全本地，可任意导出 |
| Skill 生成 | 无 | 一键生成 Claude Code Skill |
| 教学策略 | 无 | 苏格拉底 / 费曼 / 难度自适应 |
