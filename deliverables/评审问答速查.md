## 一、创新性与创意度（20 分）

**评分要点**：场景切入点是否新颖，是否解决真实痛点，交互逻辑是否有创意。

**为什么是这个项目？**

市面上没有专门为「阅读后理解与复习」设计的 AI 智能体。通用 AI 工具需要用户手动整理上下文，Anki 制卡成本高，微信读书内置 AI 又仅覆盖当前章节。知行读书把「同步 → 理解 → 复习 → 卡片化 → 英语学习」做成完整闭环，且由真实阅读痛点驱动，不是为比赛而做。

**交互逻辑创新在哪里？**

不是简单的「用户问 → LLM 答」，而是六步编排：意图分类 → 策略选择 → 难度调整 → 上下文构建 → 系统提示 → 流式响应。AI 会根据用户意图切换苏格拉底追问、费曼复述或直接回答，并根据掌握度自动升降难度，真正成为学习教练。

**核心创新点**：
1. **Agent 编排引擎**：自研六步流水线，串联意图分类、策略选择、难度自适应、5 维上下文懒加载、系统提示组装、流式输出。
2. **知识卡片 + 方法论蒸馏**：AI 自动将划线蒸馏为 concept / methodology / quote 三类卡片，并提取结构化方法论，支持一键生成 Claude Code Skill。
3. **微信读书 Skill API 集成**：依托开放网关 Skill API，实现增量同步、自动合并、防重复导入。
4. **FSRS v5 间隔重复**：Anki 同源 ts-fsrs 5.4.1，21 参数 DSR 模型，准确度比 SM-2 高 20-30%。

## 二、技术实现与复杂度（30 分）

**评分要点**：交互复杂度、AI 能力深度（Function Calling、Agent 智能体、思维链）、技术栈。

**技术栈**：

Electron 35 三进程架构 + React 19 + TypeScript 5.6 strict + Tailwind CSS 4 + Zustand 5 + sql.js 1.14 + ts-fsrs 5.4.1 + Apache ECharts 5.5.1 + Vercel AI SDK 7.x + Vitest 2。

**AI 能力实现**：

- **RAG 检索增强**：5 维 ContextBuilder 懒加载，总预算 4000 tokens，Token 节省 38-55%。
- **Function Calling**：通过 Vercel AI SDK `generateObject` 实现结构化输出，返回 JSON 格式的方法论、知识卡片、复习卡片。
- **Agent 智能体**：自研 orchestrator.ts（277 行）串联六步编排，不是简单函数调用。
- **思维链**：支持 DeepSeek R1 的 reasoning_content 实时展示。

**交互复杂度**：

多轮对话 + 跨会话记忆（偏好/事实/反馈三类长期记忆），三栏对话布局（会话列表 / 消息流 / 上下文面板），100+ IPC 通道、16 张数据库表、17 个提示词模板，6 个 ECharts 图表组件 + Recharts 统计图表。

**外部生态集成**：

微信读书 Skill API：`/shelf/sync`、`/book/get`、`/note/list`、`/review/list`，支持增量同步、自动合并、错误处理、safeStorage 加密存储。

## 三、实用价值与落地性（30 分）

**评分要点**：任务完成度、业务价值、是否具备长期使用价值。

**解决了什么实际问题？**

微信读书用户每年产生大量划线，但 90% 以上读完就忘。知行读书通过「同步 → 理解 → 复习 → 卡片化 → 英语学习」闭环，让阅读数据真正变成可复习、可应用的知识资产。

**目标用户是谁？**

18-35 岁自我成长型阅读者，微信读书重度用户。开发者本人即核心用户（年阅读量 50+ 本书），产品从第一天就是真实需求驱动。

**是否已经落地？**

已发布 v1.0.0（2026-07-25），Windows NSIS 安装包，约 125MB。下载地址：https://github.com/harryopo/zhixing-reader/releases/tag/v1.0.0。开源仓库：https://github.com/harryopo/zhixing-reader。质量门禁：`npm run verify` 一键跑 lint / typecheck / test / build，全绿才可提交。测试覆盖：667 个 passing 测试用例，AI 模块行覆盖率 91.99%。

**数据安全和隐私如何保证？**

本地优先：所有数据存储在本地 SQLite（sql.js WASM），永不上传云端。加密存储：API Key 通过 Electron safeStorage 加密存储。无追踪 SDK：不包含任何分析/追踪/广告 SDK。开源可审计：MIT 开源，任何人都可以审计。离线可用：除 AI 对话需联网外，其他功能均可离线使用。

**长期使用价值**

不是一次性工具，而是伴随阅读成长的长期产品。支持多本书、多轮对话、长期记忆、持续复习。可导出数据（JSON / Markdown / CSV），用户数据归属自己。未来规划包括跨平台同步、社区分享、知识图谱、开放 API。

## 四、用户体验与交互设计（20 分）

**评分要点**：对话反馈是否富有人性化，应用是否独立运行、操作流畅，界面布局是否清晰、交互路径是否简洁。

**对话反馈**

教学策略驱动：深度讨论用苏格拉底追问，练习用费曼复述，不是所有问题都直接回答。流式输出：基于 Vercel AI SDK `streamText()` 逐 token 推送，模拟真人打字效果。错误处理：API 调用失败、网络超时、Token 超限等场景，均有友好提示和重试建议。

**应用交互**

侧边栏导航：14 个入口统一管理，快速切换功能。三栏对话布局：左侧会话列表、中间消息流、右侧上下文面板。卡片翻转交互：概念卡、方法论卡、金句卡支持翻转查看背面。悬停查词：鼠标悬停单词弹出音标、词性、释义，280ms 防抖。主题切换：支持深色/浅色主题切换，暗色主题优先。

**界面布局**

淡雅绿色设计，极简、阅读友好。响应式布局，支持窗口缩放。关键操作有明确按钮和状态反馈。设置中心分类清晰，易于配置。

**操作流畅度**

Electron 桌面应用，独立运行，不依赖浏览器。Vite HMR，开发模式支持热重载。sql.js WASM 无原生依赖，安装简单。路由懒加载，启动速度快。
