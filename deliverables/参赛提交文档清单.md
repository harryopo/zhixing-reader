## 一、建议提交的文档清单

根据评审标准（创新性与创意度 / 技术实现与复杂度 / 实用价值与落地性 / 用户体验与交互设计），建议提交以下 **5 份文档**：

| 序号 | 文档名称 | 文档类型 | 用途 | 面向对象 |
|------|---------|---------|------|---------|
| 1 | `知行读书_项目介绍.md` | 主文档 | 项目整体介绍，包含痛点、解决方案、功能、技术栈、创新点、成果 | 评委 / 评审专家 |
| 2 | `评审问答速查.md` | 辅助文档 | 按四大评分维度准备的问答话术 | 答辩人 |
| 3 | `数据来源与合规说明.md` | 辅助文档 | 数据来源、处理方式、加密存储、合规措施 | 评委 / 合规审查 |
| 4 | `微信读书Skill_API说明.md` | 技术文档 | 微信读书 Skill API 接口、集成方式、技术实现 | 评委 / 技术评审 |
| 5 | `知行读书使用教程.md` | 用户文档 | 面向最终用户的使用教程 | 用户 / 体验评审 |

**额外建议提交**：
- `screenshots/` — 14 张应用截图（首页、书架、AI 对话、知识卡片、方法论、每日学习、生词本、统计、Token 监控、设置等）
- PPT / PDF 演示文稿 — 视觉化展示（后续由设计师制作）

## 二、文档内容概要

### 2.1 知行读书_项目介绍.md（主文档）

**内容结构**：
1. **项目概述** — 项目简介、目标用户、核心价值
2. **痛点分析** — 现有工具的问题、用户真实需求
3. **解决方案** — 知行读书的整体架构和闭环流程
4. **核心功能** — 7 大功能模块详细说明
5. **技术栈** — 完整技术栈列表
6. **核心创新点** — 3 大创新（Agent 编排、知识卡片蒸馏、微信读书 Skill API 集成）
7. **技术架构** — 三进程架构、数据库 Schema、IPC 通道
8. **关键技术实现** — FSRS v5、5 维上下文懒加载、智能体编排、安全存储
9. **项目成果** — 13 页面、100+ IPC、16 表、38 单元测试
10. **质量门禁** — lint / typecheck / test / build
11. **差异化优势** — 与 Anki、微信读书内置 AI、通用 AI 工具的对比
12. **未来规划** — 跨平台同步、社区分享、知识图谱、开放 API

**篇幅**：约 8000-10000 字

### 2.2 评审问答速查.md（答辩辅助）

**内容结构**：
1. **创新性与创意度**（20 分）
   - Q1：为什么还需要知行读书？
   - Q2：创新点具体体现在哪里？
   - Q3：Agent 和其他聊天机器人有什么不同？
2. **技术实现与复杂度**（30 分）
   - Q4：技术栈选型和理由
   - Q5：AI 能力具体实现（RAG、Function Calling、Agent、思维链）
   - Q6：交互复杂度和多轮对话支持
   - Q7：三进程架构设计
   - Q8：微信读书 Skill API 集成细节
3. **实用价值与落地性**（30 分）
   - Q9：解决什么实际问题？目标用户是谁？
   - Q10：是否已发布？用户反馈如何？
   - Q11：如何保证数据安全和隐私？
   - Q12：如何与其他工具区分开？
4. **用户体验与交互设计**（20 分）
   - Q13：界面怎么样？容易上手吗？
   - Q14：AI 对话体验如何？
   - Q15：哪些设备可用？安装复杂吗？
5. **通用问题**
   - Q16-Q20：团队、规划、不足、开源、获奖后计划
6. **技术深挖问题**
   - Q21-Q25：FSRS 算法、意图分类准确率、上下文懒加载、JSON 解析、测试覆盖
7. **答辩建议**

**篇幅**：约 6000-8000 字

### 2.3 数据来源与合规说明.md（合规审查）

**内容结构**：
1. **数据来源总览** — 四类来源表格
2. **外部数据来源：微信读书 Skill API** — 4 个接口、数据流向、最小化原则
3. **用户输入数据** — API Key 的 safeStorage 加密存储方式
4. **AI 服务商数据** — 5 维上下文发送内容、直连流程、服务商隐私政策链接
5. **本地生成数据** — 知识卡片、记忆、复习、生词本、对话历史、统计图表
6. **合规措施** — 本地优先、加密存储、无追踪 SDK、网络请求最小化、开源可审计
7. **用户权利** — 访问、修改、删除、导出、可携权
8. **第三方服务依赖** — 系统依赖、AI 服务依赖、外部 API 依赖
9. **合规声明** — 适用法律、数据出境、儿童隐私、泄露应对
10. **用户指南** — 离线使用、安全分享 Bug、彻底卸载
11. **联系我们**

**篇幅**：约 5000-6000 字

### 2.4 微信读书Skill_API说明.md（技术文档）

**内容结构**：
1. **微信读书 Skill API 是什么** — 网关地址、鉴权方式、请求/响应格式
2. **Skill API 已有能力** — 4 个核心接口详细说明
   - `/shelf/sync` — 拉取书架列表
   - `/book/bookmarklist` — 拉取划线
   - `/review/list/mine` — 拉取笔记/书评
   - `/book/chapterinfo` — 拉取章节信息
3. **知行读书基于 Skill API 做了什么** — 6 件事
   - 书架同步
   - 划线抓取
   - 笔记/书评同步
   - 章节信息获取
   - 自动同步
   - 连接测试
4. **技术实现细节** — 鉴权加密、缓存机制、重试机制、错误处理、批量处理
5. **基于 Skill API 的业务价值** — 数据归属用户、增量同步、自动合并、离线可用
6. **接口调用示例** — TypeScript 代码示例
7. **已知限制** — 接口数量、同步频率、数据范围、网络依赖

**篇幅**：约 4000-5000 字

### 2.5 知行读书使用教程.md（用户文档）

**内容结构**：
1. **安装** — Windows 安装包 + 源码运行
2. **首次配置** — API Key 配置、同步设置
3. **书架与同步** — 同步策略、自动同步
4. **AI 对话** — 对话界面、教学策略、上下文
5. **复习** — FSRS 复习、每日学习
6. **知识卡片** — 概念卡、方法论卡、金句卡
7. **每日学习与生词本** — 英语学习功能
8. **统计与 Token 监控** — 数据看板
9. **设置中心** — 7 大分类说明
10. **常见问题** — FAQ

**篇幅**：约 3000-4000 字
