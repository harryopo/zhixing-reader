# 知行读书 — 品牌徽标规范「玉璧」

一枚开了口的环：**知行合一**，而缺口就是还没迈出去的那一步——由一方铜金补上。
圆与方的对峙（环 = 知，沉淀与循环；方 = 行，落地的脚印），墨绿与铜金的搭配，
是这枚徽标想说的全部。

上一版是「平涂 emerald 色块 + 白色剪影」，实测着墨率 **84%**——满铺色块天生像系统默认图标。
现在主徽标着墨率 **23.3%**，留白 76.6%。高级感基本就是留白率。

## 一套几何，四种配色

环和方的坐标在所有稿子里**完全相同**，只有配色不同；`tests/brand-assets.test.ts` 逐字比对六处派生物。

| 文件 | 场景 | 环 | 方 | 底板 |
|------|------|----|----|------|
| `mark.svg` | 浅底 UI、文档 | 墨绿 `#0C3B2E` | 铜金 `#B08D57` | 无 |
| `mark-reverse.svg` | 深底（官网 `--surface-0: #080c0a`） | 宣纸 `#F5F1E8` | 铜金 | 无 |
| `mark-icon.svg` | 应用图标、favicon | 宣纸 | 铜金 | 墨绿圆角板 `rx=11` |
| `mark-mono.svg` | 单色印刷、烫金、雕刻 | `currentColor` | `currentColor` | 无 |
| `grid.svg` | 构造依据 | — | — | — |

派生物：`resources/icon.{png,ico}`（`npm run build:icons`）、`BrandMark.tsx`、
`src/renderer/index.html` 的 favicon、`landing/logo.svg`。

## 几何

48×48 画布，圆心 (24, 24)。

- 环：半径 **16**，线宽 **6**（内径 13 / 外径 19），`d="M32 10.14A16 16 0 1 0 40 24"`
- 开口：**60°**，区间 −60°…0°（右上），两端是平头（butt cap），不做圆头
- 方：**6×6**，中心 (38, 16) —— 正好落在开口的角平分线 −30° 上，
  到圆心距离 16.12 ≈ 环半径，即"嵌在环的缺口里"而不是随手放在旁边
- 图形外框 5…43，四周留 5 单位（10.4%）

## 尺寸

| 尺寸 | 环宽 | 方 | 结论 |
|------|------|----|------|
| 16px（托盘 / 标题栏 / 任务栏小图） | 2.0px | 2.0px | 下限，再小须换 `mark-mono` |
| 24px | 3.0px | 3.0px | ✓ |
| 32 / 48 / 256 / 1024 | 4–32px | — | ✓ |

线宽不许低于 6：16px 下就是 2px，再细会被 Windows 缩没了。

## 为什么应用图标要带底板

桌面壁纸不可控。一枚没有底板的墨绿环贴在深色壁纸上会直接消失——这是实测壁纸中灰
`#8B9298` 与深底两种情况后的结论。所以：**品牌徽标不带板，应用图标带板**，
两者共用同一组坐标。

## 配色

品牌色与 UI 交互色是**两个口径**，各自稳定：

| token | 值 | 用途 |
|-------|----|------|
| `--brand-ink` | `#0c3b2e` | 徽标环（浅底）/ 图标底板 |
| `--brand-brass` | `#b08d57` | 缺口上的方，两种主题恒定 |
| `--brand-paper` | `#f5f1e8` | 深底反白 |
| `--brand-mark` | 浅底=ink，暗档=paper | 组件里环的颜色 |
| `--primary` | `#059669`（emerald-600） | **UI 交互色，未改动** |

对比度实测（WCAG 相对亮度）：

| 组合 | 比值 |
|------|------|
| 墨绿 vs 白 | 12.50 |
| 墨绿 vs 浅侧栏 `#ecfdf5` | 11.86 |
| 宣纸 vs 墨绿底板 | 11.08 |
| 铜金 vs 墨绿底板 | 4.04 |
| 铜金 vs 白 | 3.09 |
| 宣纸 vs 暗 UI 底 `#131316` | 16.45 |

徽标本体按 WCAG 2.2 例外（1.4.3 / 1.4.11 免除 logo 对比度要求）不设限；
但**作为可点击控件使用时**属非文本组件，需 ≥3:1——上表全部满足。
铜金对白只有 3.09:1，所以铜金只做点缀，不许承载需要读的信息。

## 禁用

- 不许把环画成闭合（缺口是语义本体）、不许把方挪出缺口、不许给环加渐变或阴影
- 不许用 emerald 画徽标（那是交互色，不是品牌墨）
- 不许拉伸、旋转、加描边、在徽标上叠文字
- 最小 16px；再小用 `mark-mono.svg`

## 生成

```bash
npm run build:icons   # brand/*.svg → resources/icon.{png,ico}
```

`scripts/build-icons.mjs` 用 `@resvg/resvg-js`（MPL-2.0）光栅化，自己写 ICO 容器
（16/20/24/32/40/48/64/96/128/256 十档，条目为 PNG 压缩）。

> 不让 electron-builder 自动转：实测它的 `app-builder icon` **不接受 SVG**
> （`icons.LoadImage` 直接报错），且从 PNG 只产出 256 一档。
