# 知行读书 — 品牌徽标规范

母题：**拾级**。三级上升的台阶，既是书脊排成一列的侧影，也是「读过的每一本都是一级」的成长轨迹。
方圆对照——圆角底板承住直角台阶，对应「知」（沉淀下来的书）与「行」（迈出去的那一步）。

## 唯一真值

徽标形状只有 `brand/*.svg` 这一份来源，其余都是派生物：

| 文件 | 用途 | 说明 |
|------|------|------|
| `mark.svg` | UI 并排、官网落地页 | 标准稿，四周留 10/48 安全留白 |
| `mark-icon.svg` | 所有平台图标、favicon | 图标稿，满版 + 加粗台阶 |
| `mark-mono.svg` | 单色印刷、烫金、雕刻 | 一个色，台阶用镂空负形 |
| `grid.svg` | 构造依据 | 8 单位网格 + 三色标注，改形状时对着它画 |

派生物：`resources/icon.png`、`resources/icon.ico`（`npm run build:icons` 生成）、
`BrandMark.tsx`（UI 内联）、`src/renderer/index.html` 的 favicon、`landing/logo.svg`。
它们与源文件的一致性由 `tests/brand-assets.test.ts` 逐字比对，改形状必须同时改到位。

## 几何

48×48 网格，所有坐标为整数，台阶以 8 单位为一级。

- 标准稿：底板 `x=2 y=2 44×44 rx=10`（圆角占边长 22.7%），台阶占 `12..36` 见方。
- 图标稿：底板 `0..48 rx=11`，台阶放大到 `8..40`，最窄踏面 10 单位。
- 台阶路径：标准稿 `M12 36V28h8v-8h8v-8h8v24z`，图标稿 `M8 40V28h10V18h10V8h12v32z`。

## 尺寸

| 场景 | 用哪张 | 下限依据 |
|------|--------|---------|
| 托盘 / 标题栏 / 任务栏小图标（16px） | `mark-icon.svg` | 最窄踏面 10/48 → 3.3px |
| 任务栏（24px）/ 开始菜单（32px） | `mark-icon.svg` | 同上，≥5px |
| 应用图标（48px 以上）、窗口图标 | `mark-icon.svg` | — |
| 侧栏、关于页、官网 | `mark.svg` | 与其他元素并排时需要留白 |

**不许把标准稿直缩到 16px**：它的图形只占画布一半，实测台阶在 16px 下糊成一团
（`tests/brand-assets.test.ts` 钉住了图标稿的踏面宽度下限）。

## 颜色

平涂，无渐变、无半透明。渐变在 16/24px 上完全不收益，只会让台阶边缘发虚。

- 底板：`#059669`（emerald-600）= `design-tokens.css` 的 `--primary` = `design/colors.ts` 的 `emerald[600]`。
- 台阶：`#ffffff`；UI 内联组件用 `var(--primary)` / `var(--primary-foreground)` 跟随深浅色主题。
- 单色稿用 `currentColor`，由容器决定色。

三处色值一致性有测试兜底，改主色时三处必须一起改。

## 留白与禁用

- 安全留白 = 底板短边的 1/4（标准稿已内置）；与其他元素并排时至少再留一个台阶高度。
- 最小尺寸：数字端 16px；再小改用 `mark-mono.svg` 的镂空版。
- 禁止：拉伸变形、加描边或阴影、旋转、换非品牌色、在台阶上叠文字、把标准稿直缩成图标。

## 生成

```bash
npm run build:icons   # brand/*.svg → resources/icon.{png,ico}
```

`scripts/build-icons.mjs` 用 `@resvg/resvg-js`（MPL-2.0）光栅化，自己写 ICO 容器
（10 档：16/20/24/32/40/48/64/96/128/256，条目为 PNG 压缩）。

> 不让 electron-builder 自动转换：实测它的 `app-builder icon` **不接受 SVG**
> （`icons.LoadImage` 直接报错），且从 PNG 生成的 ICO **只有 256 一档**，
> 16px 托盘位会被 Windows 硬缩。

## 无障碍

徽标本体按 WCAG 2.2 例外条款（1.4.3 / 1.4.11 对 logo 免除对比度要求）不设限；
但**作为可点击控件使用时**属非文本组件，与相邻背景需 ≥3:1。实测（WCAG 相对亮度公式）：

| 组合 | 对比度 | 结论 |
|------|--------|------|
| `#059669` 底板 vs 白 | 3.77:1 | 过 3:1，不到 4.5:1 → 徽标上不许放需要读的正文 |
| `#059669` 底板 vs 浅色侧栏 `#ecfdf5` | 3.58:1 | 过 3:1 ✓ |
| `#059669` 底板 vs 暗侧栏 `#131316` | 4.92:1 | 过 3:1 ✓ |
| 白色台阶 vs `#10b981`（若跟随暗色 `--primary`） | **2.54:1** | 不合格 → 这就是徽标颜色不跟主题漂移的原因 |
