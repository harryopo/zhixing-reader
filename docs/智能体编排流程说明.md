# 知行读书 — 智能体编排流程说明（PPT 用）

> 本文档用于答辩 PPT 讲解智能体架构，不涉及 UI 实现细节。
> 对应代码：`electron/agent/` 目录

---

## 一、六步智能体流水线

知行读书的 AI 对话不是简单的「用户问 → LLM 答」，而是经过六步编排，让回答更精准、更贴合学习场景：

```
用户提问
   │
   ▼
① 意图分类  ──→  ② 策略选择  ──→  ③ 难度调整  ──→  ④ 上下文构建  ──→  ⑤ 系统提示  ──→  ⑥ 流式响应
```

### ① 意图分类（intent-classifier.ts）
识别用户问题的四种意图：
- **知识查询**：「什么是 X」「X 是什么意思」→ 事实/概念检索
- **深度讨论**：「为什么」「你怎么看」「对比」→ 批判性思辨
- **教学练习**：「考考我」「教我」「复述」→ 苏格拉底/费曼训练
- **闲聊问候**：「你好」「谢谢」→ 轻量回应

**实现**：关键词匹配 + 对话上下文分析（识别追问、肯定回答等），不依赖 LLM，零延迟。

### ② 策略选择（strategy-selector.ts）
根据意图匹配教学策略 × Bloom 认知难度等级：

| 意图 | 教学策略 | Bloom 等级 |
|------|---------|-----------|
| 知识查询 | 直接回答（direct_answer） | L1 记忆 |
| 深度讨论 | 苏格拉底提问（socratic） | L3 应用 |
| 教学练习 | 费曼讲解（feynman） | L2 理解 |
| 闲聊问候 | 直接回答 | L1 记忆 |

### ③ 难度调整（state-tracker.ts）
基于用户答题表现自动升降 Bloom 等级：
- **升级**：某概念连续答对率 ≥ 85% → 提升一级，引导批判性思考
- **降级**：连续答错率 ≥ 60% → 回退一级，巩固基础
- **冷却**：每次升降级后 30 分钟内不再变更，避免难度抖动

状态在会话内维护，概念掌握度实时跟踪。

### ④ 上下文构建（context-manager.ts + 5 个 builder）
从数据库组装 RAG 上下文，总预算 4000 tokens，按优先级分配：

| 优先级 | 构建器 | 内容 | Token 预算 |
|--------|--------|------|-----------|
| P1 | BookBuilder | 当前书籍段落、章节、书签 | 1500 |
| P2 | MethodologyBuilder | 该书的方法论 + 教学策略模板 | 800 |
| P3 | KnowledgeCardBuilder | RAG 检索的相关知识卡片（向量 top-k=5） | 700 |
| P4 | MemoryBuilder | 最近 8 轮对话历史 + 长期记忆 | 500 |
| P5 | UserProfileBuilder | 用户画像（当前禁用） | 500 |

超出预算自动按优先级截断。

### ⑤ 系统提示组装（system-prompt.ts）
将人设 + 策略 + 难度 + 掌握概念拼成系统提示，变量 `{book_title}`/`{methodology}`/`{bloom_level}` 等由 builder 实时填充。用户可在提示词中心自定义这个模板。

### ⑥ 流式响应（orchestrator → ai-sdk-service）
基于 **Vercel AI SDK** 的 `streamText()` 流式输出，逐 token 推送到前端，支持随时取消。响应完成后：
- 更新概念掌握度（根据用户后续反应判断对错）
- 更新方法论练习次数和掌握度
- 提取长期记忆（偏好/事实/反馈三类）写入 `memories` 表

## 二、技术栈

| 层 | 技术 |
|----|------|
| 编排核心 | 自研 `orchestrator.ts`（277 行）串联六步 |
| LLM 调用 | **Vercel AI SDK 7.x**（`streamText` + `generateObject`） |
| 模型适配 | `@ai-sdk/openai-compatible`（一套代码兼容 OpenAI/Anthropic/DeepSeek/通义等所有兼容 API） |
| 向量检索 | Vectra（本地向量库）+ OpenAI Embedding |
| 上下文预算 | 自研 `ContextManager` 策略模式 |

**为什么选 Vercel AI SDK**：原生 TypeScript + 流式一等公民 + 结构化输出（Zod schema）+ 工具调用，替代了原本 1441 行手写 fetch+SSE 代码。

## 三、核心设计理念

1. **教学策略驱动**：不是所有问题都直接回答。深度讨论用苏格拉底追问，练习用费曼复述，让 AI 扮演「教练」而非「百科」
2. **难度自适应**：Bloom 六级认知层次 + 答题反馈自动升降，避免「太难放弃 / 太简单无聊」
3. **RAG 上下文**：回答基于用户自己的读书笔记 + 知识卡片，而非模型通用知识，做到「基于你读过的书」
4. **记忆持久化**：对话中抽取偏好/事实/反馈三类记忆，跨会话记住用户

---

## 四、一句话总结

> 知行读书的智能体 = **意图识别 + 策略匹配 + 难度自适应 + RAG 上下文 + 流式输出 + 记忆提取**，六步编排让 AI 从「问答机器」升级为「懂你读什么、懂你学到哪、懂怎么教你的学习教练」。
