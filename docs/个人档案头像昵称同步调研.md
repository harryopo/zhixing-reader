### 待做（前端，Trae 接线）

`src/renderer/src/pages/Profile.tsx` 当前只从本地 settings 读：
```typescript
api.settings.get('userNickname')   // 手动填的
api.settings.get('userAvatarUrl')  // 手动填的
```
**没有调用** `window.electronAPI.weread.getUserProfile()`。

**建议接线点**：`Profile.tsx:121` 的 `loadExtras` effect 里，加一段：

```typescript
// 优先从微信读书同步昵称/头像（仅当本地未手动设置时）
try {
  const result = await api.weread.getUserProfile()
  if (result?.success && result.profile) {
    // 昵称：本地未设则用微信读书的
    if (!safeStr(profile.nickname) || profile.nickname === DEFAULT_PROFILE.nickname) {
      setProfile((p) => ({ ...p, nickname: result.profile!.nickname }))
      await api.settings.set('userNickname', result.profile.nickname)
    }
    // 头像：本地未设则用微信读书的
    if (!safeStr(avatarUrl) && result.profile.avatarUrl) {
      await api.settings.set('userAvatarUrl', result.profile.avatarUrl)
    }
  }
} catch {
  /* 降级：保持本地设置 */
}
```

### 注意

1. `fetchUserProfile` 调 `/user/info` `/user/profile`，这两个接口**不在微信读书公开文档**里，是猜测的候选。若网关不支持，会返回 `{ success: false, message: '微信读书 API 暂不支持获取头像/昵称，请手动填写' }`，前端应静默降级（已有 try/catch）
2. 优先级：**本地手动设置 > 微信读书同步**（用户手动改过的别被覆盖）
3. 调用时机：进 Profile 页时调一次即可，不必每次 render
