## 1. DESIGN SPECIFICATION

| 项 | 内容 |
|----|------|
| **Purpose** | 当前三栏布局（240 会话 + 对话 + 280 上下文）在默认展开时把对话区压到不足 60% 宽度；右栏含假数据（0% 进度条、「引用笔记(0)/暂无笔记」空态）与超大书封，信息价值低、占地大。目标：对话内容成为绝对主角，历史与书籍上下文收编为轻量控件。 |
| **Aesthetic Direction** | **沿用既有设计系统（OVERRIDE 声明）**：本页是既有应用的布局重构，不做新视觉方向。沿用 emerald 绿主题 / `--card/--border/--muted-foreground/--radius` 等 CSS 变量 / 现有 Icon SVG 集 / 中文界面系统字体栈。本次改的是**信息架构与空间分配**，不是皮肤。 |
| **Color / Typography** | 全部取自现有 token，零新增色值、零新增字体。 |
| **Layout Strategy** | 三栏 → **单栏全宽对话 + 左滑出抽屉（历史）+ 输入区上下文条（书籍）**。参照 ChatGPT/Claude 的「历史收纳进抽屉、附件以 chip 常驻输入区」范式。 |

## 2. 用户问题 → 对策映射

| # | 用户指出的问题 | 对策 |
|---|----------------|------|
| 1 | 历史会话列表大、占位 | **删除常驻左栏** → 头部「☰ 历史」触发**左滑出抽屉 320px（overlay+遮罩）**，下面全是对话 |
| 2 | 关联书籍 UI 很大（大书封 300px） | 书籍收编为**输入区上方 ContextBar**：封面 40×56 + 书名/作者单行 + [更换][×取消]，常驻不折叠 |
| 3 | 进度条显示 0% | **删除**（阅读进度同步本就未写真实值，展示即假数据；A11 去伪存真原则） |
| 4 | 「引用笔记(0)/这本书暂无笔记」 | **整节删除**。真实检索已由「调取知识库」RetrievalPanel 呈现（命中多少条是真的），空态文案无信息量 |
| 5 | 不折叠时对话区挤 | 对话区**全宽**，消息列 `max-width: 820px` 居中（超宽屏可读性），两侧呼吸留白 |
| 6 | 快捷按钮占两行很挤 | 收为**输入框下方单行** 4 个小 chip，右侧发送按钮独立 |

## 4. 分区规格

### 4.1 ChatHeader（新，52px）
- `[☰ 历史对话]`：ghost 图标按钮，开启抽屉；抽屉开启时变 `aria-expanded=true`。
- 会话标题 + `N 条消息`：沿用现有文案。
- `[＋ 新对话]`：ghost 按钮（原左栏头部的 + 迁移至此，一键可达）。
- 无右栏后，原 `Badge(书名)` 移除（书籍由 ContextBar 承担，避免两处重复）。

### 4.2 SessionDrawer（新组件，overlay）
- 宽 320px，`position: fixed; left:0; top:76px; bottom:0`（Topbar 之下），遮罩 `rgba(0,0,0,.35)`。
- 内容 = 现有 sessions 列表逻辑**原样迁移**（标题/相对时间/删除/切换），头部加 [＋ 新对话] 与搜索框（可后期）。
- 动画：`transform: translateX(-100%→0)` 200ms ease；关闭反向。
- 可访问性：`role="dialog"` `aria-modal` Esc 关闭、焦点困笼（沿用通知面板先例）。
- 无路由跳转、无状态持久化需求（纯 overlay，不占布局）。

### 4.3 ContextBar（新组件，64px，输入区上方）
- 仅在 `currentBookId` 存在时渲染；无书时显示一行虚线 ghost「＋ 关联书籍后 AI 将基于笔记作答」点击打开书籍选择 popover（复用 ContextPanel 的选书逻辑）。
- 封面 **40×56**、书名单行截断、作者次行；操作：`更换`（popover 选书）与 `× 取消关联`。
- **删除**：进度条、阅读进度百分比（假数据）。

### 4.4 输入区（改造）
- 单行布局：textarea 自适应高（现有逻辑不变），右侧发送按钮。
- 快捷 chips 单行：深度思考 / 费曼教学 / 深度提问 / 考考我，高度 28px、字号 0.78rem；选中态沿用现有绿底。
- RetrievalPanel（调取知识库）保持出现在消息流内，不动。

### 4.5 删除清单（去伪存真）
| 删除项 | 位置 | 理由 |
|--------|------|------|
| 书籍进度条 + 0% | 右栏 book-progress-mini | 同步未写真实进度，展示即假数据 |
| 引用笔记 (N) 整节 + 「这本书暂无笔记」 | 右栏 context-section | 空态噪音；真实命中已由 RetrievalPanel 呈现 |
| 280px 右栏 / 240px 左栏 | 布局容器 | 职责已迁移（抽屉 + ContextBar） |
| 头部书名 Badge | messages-head | 与 ContextBar 重复 |

> 保留但校准：若未来同步真实阅读进度，可在 ContextBar 书名旁以单行文字呈现「已读 42%」，不做进度条。
