# 知行读书设置中心使用教程

本文档汇总了知行读书设置中心各模块的用途说明，便于后续整理为正式帮助文档或新用户引导。

---

## 1. 设置总览

在设置首页左侧选择具体分类即可配置对应模块。所有设置均通过本地数据库（sql.js）持久化，AI 模型与智能体编排已解耦为独立模块，方便分别维护。

各分类职责如下：

- **账户**：开启「继承微信读书信息」后无需本地填写昵称/头像（同步功能将在后续版本上线）。
- **AI 配置**：仅配置 LLM 服务与提示词模板；与智能体编排完全解耦。
- **智能体编排**：独立页面，配置意图识别阈值、教学策略与上下文预算。
- **微信读书**：配置 API Key 并开启同步后，划线与笔记将自动同步到本地。
- **外观**：仅保留深浅色主题切换，字体与界面密度已移除（无效功能）。

## 2. 账户设置

### 2.1 继承微信读书信息

- **个人信息卡片**：开启后将在后续版本中自动从微信读书同步个人信息（当前版本暂未实现）。
- **功能模块卡片**：开启后使用微信读书账户信息，本地信息无需手动维护。

## 3. AI 配置

### 3.1 提示词模板

提示词模板（Prompt Template）控制 AI 在不同场景下的回复风格与教学策略。4 个内置模板对应「意图分类」的 4 种意图：

- **通用对话**（默认）
- **知识查询**（RAG 检索）
- **教学练习**（苏格拉底 + 费曼）
- **深度讨论**（批判性思辨）

操作说明：

- 点击「编辑」跳转至管理面板修改具体提示词内容，持久化到 `prompt-storage`，对应 `agent.system` / `agent.intentKeywords` / `agent.strategy.*` 等 prompt id。
- 点击「新建模板」可创建自定义提示词，保存到本地 `settings.json`，便于在管理面板中复用。
- 开关仅控制该模板是否在当前场景下生效，不影响模板内容。

## 4. 数据与存储

### 4.1 存储用量看板

展示本地存储的三类占用：

- **SQLite 数据库**：书籍、笔记、卡片、对话等业务数据，运行于 sql.js WASM。
- **缓存**：微信读书 API 内存缓存与图片/网页临时文件。
- **向量库**：Vectra 本地索引。

KPI 计数通过 `admin.getStats` 实时拉取。容量上限为设计稿默认值 512MB，仅作可视化参考，无硬性配额。

### 4.2 缓存管理

三类清理操作的差异化用途：

- **清理缓存**：仅清除微信读书 API 内存缓存（请求结果），不删除本地数据，安全可常用。
- **清理历史记录**：删除全部对话记录（`conversations` + `chat_messages` 表），影响 AI 对话上下文，需二次确认。
- **清理向量索引**：跳转至管理面板手动操作本地 Vectra 索引，重建索引将临时影响 AI 检索能力。

### 4.3 数据导入导出

四种导入导出格式的差异化用途：

- **导出全部数据（JSON）**：完整备份书架/笔记/卡片，可用于跨设备迁移或归档。
- **导出笔记（Markdown）**：兼容 Obsidian/Logseq 等双链笔记软件，仅划线 + 笔记，不含卡片。
- **导出复习数据（CSV）**：FSRS 调度记录，可用 Excel/Numbers 做复习行为分析。
- **导入数据（JSON）**：从备份恢复，自动合并（冲突记录跳过，不覆盖现有数据）。

### 4.4 FSRS 参数配置

FSRS（Free Spaced Repetition Scheduler）是间隔重复算法，决定每张卡片的下次复习时间。

三个参数的用途：

- **请求级别**（1-10）：越高复习越频繁，默认 3 适合多数读者。
- **难度衰减**（0-1）：控制记忆衰减速度，默认 0.2。
- **最大间隔**（天）：限制单张卡片最长复习周期，默认 365 天。

参数保存路径：`settings.set` 持久化 UI 值，`fsrs.setParameters` 同步到引擎，立即影响后续复习调度。

### 4.5 重置数据库

本操作将清空本地 SQLite 数据库的全部业务表（书籍、笔记、卡片、对话、记忆、复习记录等）并重启应用。

调用 `system.resetDatabase`，主进程 500ms 后执行 `app.relaunch()` + `app.exit(0)`。该操作**不可撤销**，请务必先在「数据导入导出」卡片中导出 JSON 备份。

三次确认机制：

1. 警告数据丢失
2. 确认已备份
3. 最终确认
